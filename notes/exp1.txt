O que não precisa do cityscapes:

- gtCoarse — anotações mais grosseiras, não recomendadas para baseline
- rightImg8bit — câmera direita, fora do escopo
- disparity — profundidade, não é segmentação semântica
- leftImg16bit — HDR, sem necessidade para o seu cenário
- As versões foggy e rain — interessantes só se quiser explorar robustez, mas fora do plano atual
- trainextra — 19.998 imagens extras com anotações grosseiras, desnecessário

FASE A — Leitura estrutural
  ├── Listar todos os pares (imagem, máscara) por split
  ├── Verificar resolução de cada imagem
  └── Confirmar integridade (arquivos corrompidos, pares ausentes)

FASE B — Análise das máscaras (labelIds originais)
  ├── Contar pixels por classe em todo o dataset
  ├── Contar aparição de cada classe por imagem
  ├── Calcular grau de desbalanceamento
  └── Contar pixels void/ignore nativos

FASE C — Aplicar mapeamento da pesquisa
  ├── Converter labelIds → 5 classes + ignore (255)
  ├── Recalcular distribuição com as novas classes
  └── Identificar classes críticas com poucos pixels (pedestres, obstáculos)

FASE D — Geração de saídas
  ├── Gráfico de barras: frequência de pixels por classe
  ├── Gráfico: % de imagens com cada classe presente
  ├── Histograma de resoluções (deve ser uniforme no Cityscapes)
  ├── Amostras visuais: imagem + máscara sobreposta (antes e após mapeamento)
  └── Relatório: dataset_statistics.json + dataset_statistics.csv
